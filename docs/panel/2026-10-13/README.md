# Specialist panel, 2026-10-13

Four review-only agents (`.claude/agents/`) reviewed the live site in three rounds. The plan
that came out of it is [ROADMAP.md](../../../ROADMAP.md).

| Round | What each specialist did |
|---|---|
| 1 | Reviewed the site independently, from their own lane |
| 2 | Read the other three's round-1 reports and agreed, challenged or re-ranked |
| 3 | Gave a final ranked list of next steps, with a test for when each is done |

Between rounds the coordinator re-checked the claims that would most change the plan
against the database, the code and the original sources. Those checks are in the
`coordinator-notes` files.

Screenshots and other scratch files the specialists mention were kept only for the
session and are not in the repository. File and line references are to commit `6884f51`.
